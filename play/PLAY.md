# Spectr IT NetMTR-2 — загрузка в Google Play

Пакет: `uz.spi.netmtr_2`  
Версия: `2.0.0` (versionCode `1`)  
Файл для загрузки: `app/build/outputs/bundle/release/SpectrIT-NetMTR-2-release.aab`  
Иконка 512×512 для карточки в консоли: `play/icon-512.png`  
Открытый сертификат ключа загрузки: `play/upload-certificate.pem`  
SHA-256: см. `play/sha256.txt`

Ключ загрузки (`keystore/spectr-upload.jks`) и пароли лежат только на этой машине и в git не попадают. Сохраните копию jks и `keystore/CREDENTIALS.txt` отдельно. Без них нельзя выпустить обновление, если включена загрузка своим ключом.

## Отпечаток для регистрации пакета

В поле SHA-256 вставьте строку из `play/sha256.txt` (с двоеточиями).

## Что указать в консоли

- Название: Spectr IT NetMTR-2
- Категория: Инструменты
- Приложение не передаёт отчёт на сервер. Пользователь сам отправляет его через «Поделиться» или сохраняет PDF.
- Данные: модель устройства, сеть, публичный IP и результаты проверок остаются на телефоне, пока пользователь их не отправит.
- Разрешения: интернет, состояние сети и Wi‑Fi, удержание экрана на время проверки.
- Целевая аудитория: не для детей.
