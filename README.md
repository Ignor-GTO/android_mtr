# NetMTR

Android-приложение для проверки стабильности канала: пинг, трассировка и MTR в духе WinMTR. Результат собирается в текстовый отчёт, который можно отправить администратору почтой или мессенджером.

Приложение само никуда отчёт не отправляет.

## Что входит в проверку

Полная проверка собирает:

- модель устройства, версию Android и тип сети (Wi‑Fi, мобильная, VPN);
- локальные адреса, шлюз и DNS;
- внешний IP;
- время DNS и контрольный запрос `https://www.google.com/generate_204`;
- время TCP-подключения к цели на порт 443;
- пинг шлюза и пинг цели: потери, мин/сред/макс, джиттер;
- MTR: по каждому прыжку потери, задержка и джиттер.

Отдельно можно запустить только MTR, одну трассировку или только пинг.

Пробы идут через системную утилиту `ping`, root не нужен. На части прошивок ICMP запрещён: это будет видно в отчёте. Если промежуточный маршрутизатор молчит, а следующие прыжки отвечают, отчёт прямо пишет, что это обычно фильтр traceroute, а не обрыв канала.

## Сборка APK

Каждый push в `main` и ручной запуск собирают debug APK в GitHub Actions.

1. Откройте вкладку Actions.
2. Выберите последний успешный запуск **Build APK**.
3. Скачайте артефакт `NetMTR-<номер>`.
4. Установите APK на телефон. Для этого нужно разрешить установку из этого источника.

Повторно запустить сборку можно на той же странице через **Run workflow**.
